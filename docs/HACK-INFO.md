# Physical AI Hackathon, DARE Campus Zurich

Tue 29 Sep 2026 · DARE Campus, The JED, Zurich-Schlieren (S-Bahn ~15 min from Zurich HB, short walk)

## Schedule

| Time | |
|---|---|
| 08:30 | Doors |
| 10:30 | Team formation (teams of 1 to 5) |
| 10:45 | Build starts |
| 13:30 | Checkpoint: 2 min per team, scope correction, not judging |
| 17:00 | Code freeze, set up at the demo bar |
| 17:30 | Live demos, 4 min per team |
| 19:00 | Results, room stays open after |

## Brief and judging

- One track: Physical AI, any interpretation. Software-only, hardware, or both, all on equal footing.
- Judged on: does it work, how hard was the problem, how far did we get, and above all, does it
  make people look up.
- The demo must run live in front of the judges. Video fallbacks do not score.
